# **App Name**: MyIELTS Platform

## Core Features:

- AI-Powered Practice Tests: Simulate IELTS exams with AI-generated questions tailored to the user's skill level, covering all four sections: Listening, Reading, Writing, and Speaking. Provides detailed performance analytics and feedback.
- Vocabulary Learning: Interactive vocabulary hub offering categorized word lists, example sentences, and visual aids. Track the user's vocabulary learning progress and quiz performance, and suggest contextually appropriate terms while writing in the chat app using an AI tool.
- Personalized Roadmap Generation: Generative AI-driven learning path creation. Recommends study materials and daily/weekly tasks tailored to the user's target score, skill gaps, and available time, including an estimated timeline.
- AI Chat Tutor: AI chat application providing instant feedback on grammar, vocabulary, and style to help improve writing and speaking skills, with support for both English and Vietnamese, in either textual or voice based interfaces. Includes study tips and answers general questions regarding the IELTS exam
- Performance Dashboard: Visualized tracking of practice scores and key statistics in an integrated user dashboard, including strengths and weaknesses analysis with suggested remedial content and vocabulary.
- Account creation and authentication: Allow the user to create an account to save the progress

## Style Guidelines:

- Primary color: Soft pink (#F48FB1) to evoke feelings of trust and approachability.
- Background color: Very light pink (#FFF7FB) to keep the website airy and clean.
- Accent color: Light coral pink (#FFB6C1) for highlights and interactive elements.
- Headline font: 'Poppins' sans-serif for a modern and clean look.
- Body font: 'Inter' sans-serif for readability.
- Use clean and consistent line icons from Heroicons or Lucide to represent features.
- Cards with rounded corners (rounded-2xl) and subtle shadows (shadow-md) to create a modern look.
